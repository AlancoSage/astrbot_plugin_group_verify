# astrbot_plugin_group_verify 入群验证

AstrBot 入群验证插件：新人入群后发送随机数字验证码，需在规定时间内发送验证码完成验证；超时可配置移出群聊或禁言。

## 功能

- 新人入群自动发送验证码（支持 4-8 位可配置）
- 三层延迟均可自定义：
  - **发送延迟**：入群后等待 N 秒再发送验证提示
  - **答题时限**：发送验证提示后 N 秒内未验证通过则超时
  - **超时处理延迟**：超时后等待 N 秒再执行踢出/禁言
- 超时处理动作：无操作 / 移出群聊 / 禁言（禁言时长可配置）
- 每群单独配置验证规则（开关、延迟），优先于全局配置
- 群黑白名单模式
- 验证通过 / 超时提示语可自定义

## 管理指令

| 指令 | 说明 |
| --- | --- |
| `/验证延迟 <秒>` | 设置当前群验证提示发送延迟 |
| `/验证时限 <秒>` | 设置当前群答题时限 |
| `/验证开关 [开/关]` | 开启/关闭当前群验证 |
| `/验证查看` | 查看当前群验证配置 |
| `/验证删除` | 删除当前群单独规则，恢复全局默认 |

仅管理员可用。

## 配置

在 AstrBot 插件配置面板中修改，所有延迟均为秒数，0 表示立即执行/永不超时（按各字段说明）。

## 依赖

仅依赖 AstrBot 内置模块与 aiocqhttp 适配器（NapCat / Lagrange 等 OneBot 实现），无额外 pip 依赖。
